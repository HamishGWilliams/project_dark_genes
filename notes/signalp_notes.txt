SignalP is a bit different from DIAMOND, InterProScan, and eggNOG-mapper because it is usually distributed under a licence from DTU/SignalP rather than as a normal open package. So the first step is to check whether Maxwell already has it as a module. If not, I need to download it from the official SignalP site after agreeing to the licence, then transfer/install it in the user space.

For this project, SignalP should be run on the representative protein set, and it will form the secretory-signal annotation layer for the final master table. The tracker already lists SignalP as a pending annotation step for unresolved candidates.

# Create 100-protein SignalP test sey
python3 - <<'PY'
from pathlib import Path

inp = Path("02_annotation/input/equina_representative_longest_per_gene.no_stop.fa")
out = Path("02_annotation/signalp/test_input/equina_representative_test100.no_stop.fa")
out.parent.mkdir(parents=True, exist_ok=True)

n = 0
write = False

with inp.open() as fin, out.open("w") as fout:
    for line in fin:
        if line.startswith(">"):
            n += 1
            write = n <= 100
        if write:
            fout.write(line)

print(f"Wrote {min(n, 100)} proteins to {out}")
PY

grep -c '^>' 02_annotation/signalp/test_input/equina_representative_test100.no_stop.fa
